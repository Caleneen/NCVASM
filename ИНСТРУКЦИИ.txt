На строке не должно быть ничего, помимо чёткой инструкции/операнды, иначе интерпретатор ничего не сделает за цикл, кроме пропуска строки.
Между строк с инструкциями вы можете писать хоть что, то есть комментировать код, однако это будет замедлять исполнение т.к. интерпретатор будет обрабатывать все строки, включая пустые.
Разделять строки с помощью enter.
Можно писать код через блокнот, и в приложении загружать программу через селектор "Загрузить" в меню "Действия".
Все значения при запуске интерпретатора равны 0 (число) или пустоте (строка).
При запуске интерпретатора происходит подзагрузка сегментов по файлу seglist.txt из папки Resources.

Инструкции зависят от регистра, и занимают строгое количество строк.
При окончании исполняемых инструкций ваша программа заканчивает исполнение.
При прыжке за пределы программы курсор передвинется либо на 0 строку (когда желаемая строка раньше нуля), либо на последнюю (когда желаемая строка дальше последней).

При запуске интерпретатора происходит загрузка файла BIOS.txt из папки под именем [BIOS] (задаётся в settings.ini, что находится около NCVASM.exe), что находится в Resources, что находится в папке с интерпретатором, и сразу начинается быстрое исполнение.
При загрузке программы с помощью интерфейса происходит сброс состояний сегментов и регистров, а также отключение исполнения.

В интерпретаторе есть несколько настроек что задаются пользователем в меню сверху:
"Переключить выполнение" - включает/ставит на паузу исполнение кода;
"Быстрое выполнение" - выполняет 10000 инструкций как можно быстрее или пока не наткнётся на инструкцию RENDER/PAUSE;
"Приблизить" - увеличивает scale на 1 (до 4), который в свою очередь умножает размер окна на самого себя;
"Отдалить" - то-же, что и "Приблизить", но уменьшает scale на 1 (до 1);
"Переключить интерфейс" - включает/выключает отображение значений регистров и последней строки;
"Оптимизация меток" - при следующей загрузке программы прогоняет алгоритм, который при нахождении не цифренных меток LIN заменяет их на цифренные;
"Широкий режим" - умножает ширину окна на 2;
"Режим отладки" - активирует кнопку ". Del" (на NumPad), что делает дамп большинства информации в папку "Документы/NCVASM_DUMPS" по разным файлам.

Дебаг окно отображает: FPS консоли, FPS программы, и количество циклов. При нажатии на Numpad 0 при открытом окне количество циклов сбрасывается до 0.


Вместо TYPE нужно писать I (целое число), REG (регистр), ADR (адрес памяти), LIN (строка), INP (ID ввода), VAR (алиас адреса), FIL (№ строки открытого .ncvdat файла).

I = 32-битное целое подписанное число.

REG = один регистр из списка:

READ ONLY:
CLIN = номер строки последней исполненной инструкции
SUM = результат последнего ADD
DIF = результат последнего SUB
PRO = результат последнего MUL
RAT = результат последнего DIV
SGS = состояние сегмента с проверки
SGC = RGB коэффицент сегмента с проверки
BGC = RGB коэффицент фона с проверки
SEGR = отзеркаливание сегмента с проверки
CMP = результат сравнения (-1 = число меньше, 0 = числа равны, 1 = число больше)
ORR = результат OR
ANDR = результат AND
XORR = результат XOR
SHLR = результат SHL
SHRR = результат SHR
CURX = X позиция курсора мыши / 8 (округлено до меньшего)
CURY = Y позиция курсора мыши / 16 (округлено до меньшего)
(CURX и CURY совпадают с позициями символов)

READ/WRITE
SLT1 - SLT10 = свободные регистры
CMEM = динамический адрес памяти. Можно вставить как значение ADR.

ADR = целое число от 0 до 999; CMEM (его значение), SLT1-10 (их значение). При чтении возвращает значение адреса.

LIN = целое число от 0 до 2147483647; имя строки без двоеточия; регистры SLT1-10. При чтении возвращает номер строки.

INP = ID из списка "kbd.txt" числом или регистром SLT1-10. При чтении возвращает boolean зажата ли клавиша.

VAR = имя ASSIGN адреса; может быть написан любыми символами. При чтении возвращает значение "переменной".

FIL = № строки загруженного файла .md (отсчёт с 0) или SLT1-10. При чтении возвращает содержимое строкой число.

Разрешение - 320x240 (4:3)
0 - левый край по X
39 - правый край по X
0 - верхний край по Y
14 - нижний край по Y
В этой зоне умещаются 600 сегментов фона и 600 сегментов символов размером 8x16.


ЗНАЧЕНИЯ ЦВЕТА:
0 - чёрный, 255 - красный; 65280 - зелёный; 65535 - жёлтый; 16711680 - синий; 16711935 - пурпурный; 16776960 - голубой; 16777215 - белый.
1 - единица в красном спектре; 256 - единица в зелёном спектре; 65536 - единица в синем спектре.
